# Product Vision

**Status:** Proposed

## One-sentence vision

Turn everyday exercise into a playful RPG journey where each activity builds a recognizable character and every workout gives the user a satisfying sense of progress.

## User promise

“Whatever movement I do, I can see it matter.”

The app should translate a workout into a small, immediate reward and also show how that reward contributes to a longer-term identity.

## Core loop

1. The user completes an activity in real life.
2. The app imports or records the activity.
3. The app explains the XP earned.
4. One or more skills progress.
5. The user sees a level-up, unlock, quest, or class change when appropriate.
6. The user chooses what to pursue next.

## Tone

- Encouraging rather than judgmental.
- Game-like without requiring gaming expertise.
- Silly in names and flavor text, clear in numbers and actions.
- Celebratory without turning rest days into failure.

## Non-goals for the mockup phase

- Building a medically accurate training program.
- Designing a complete social network.
- Solving every exercise type or wearable integration.
- Finalizing balance, rewards, or monetization.
